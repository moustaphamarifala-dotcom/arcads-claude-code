# Script viral — Collection multicolore (montage vidéo réelle)

**Source :** vidéo brute envoyée par le client (23,5 s, balayage sur une
rangée de bazins pliés de couleurs différentes : rouge, bleu, doré, vert, violet).

## Script (voix off, 18,3 s)

> Attends avant de scroller... regarde cette collection de bazins !
> Rouge, bleu, doré, vert, violet... chaque couleur est unique, teinte à la main.
> Commente ta couleur préférée !
> Et pour commander, écris-nous sur WhatsApp, au cinq cinq, treize, trente-quatre, quatorze.
> Bazin Mari Falah, le choix ne s'arrête jamais.

## Pourquoi ce script est pensé pour viraliser

- **Hook dans la première seconde** ("Attends avant de scroller...") — casse le scroll automatique, technique n°1 pour la rétention TikTok/Reels.
- **CTA d'engagement** ("Commente ta couleur préférée") — pousse aux commentaires, ce qui booste l'algorithme (plus de commentaires = plus de portée).
- **Rythme rapide** — une couleur listée toutes les ~1s, correspond au balayage visuel de la vidéo.
- **Conversion à la fin** — numéro WhatsApp dit à voix haute + affiché en CTA final.

## Fichiers

- Voix : `remotion-studio/examples/viral-collection.json` (référence l'audio dans le scratchpad de session — à régénérer si besoin via `tts_viral_collection.py`)
- Rendu : moteur Remotion (`remotion-studio/`), plan `type: "video"` sur le fichier source du client + zoom lent + sous-titres synchronisés + CTA.
